First public release of Open-TmuxTabs.

## Quick start (Windows, no Python needed)

```powershell
irm https://github.com/schlingensiepen/tmux-helper/releases/latest/download/open-tmux-tabs.exe -OutFile "$env:TEMP\open-tmux-tabs.exe"; Start-Process "$env:TEMP\open-tmux-tabs.exe" -Wait
```

Requires Windows Terminal and the OpenSSH client (both part of current Windows), plus tmux on the remote hosts.

## Assets

| File | Use |
|---|---|
| `open-tmux-tabs.exe` | Standalone Windows executable, no Python needed |
| `open_tmux_tabs-2.0.0-py3-none-any.whl` | Python wheel for `pipx run` / `pipx install` (Python 3.10+) |
| `*.sha256` | SHA-256 checksums |
| `start.cmd`, `ssh-config-beispiel.txt`, `LIESMICH.md` | Starting from a network share via pipx (clawbook-lehre container) |

## Contents

- Six views: New host, host detail with session selection and creation, failed host with reconnect and SSH key setup, Open with quick start, Direct session, Show all
- Batch launch into one Windows Terminal window or one window per host
- Seven UI languages (en, de, fr, es, eo, tlh, ur); default follows the system language
- Translations are bundled with the wheel and the executable
